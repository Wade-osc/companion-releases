# Companion — téléchargements

Installateurs officiels de **Companion**, l'espace numérique des établissements scolaires, par OS Catalysts.

Ce dépôt ne contient **aucun code source** : il sert uniquement à distribuer les installateurs, publiés comme fichiers de chaque [release](../../releases).

| Système | Fichier |
|---|---|
| Windows 10 / 11 | `Companion-<version>.exe` |
| macOS | `Companion-<version>.dmg` |
| Ubuntu / Debian | `Companion-<version>.deb` |
| Autres distributions Linux | `Companion-<version>.tar.gz` |

Les releases sont **immuables** : une fois publiée, une version ne peut plus être modifiée. L'empreinte SHA-256 de chaque fichier est affichée par GitHub à côté du fichier ; Companion la vérifie avant toute installation.

Une fois installé, Companion se met à jour depuis l'application.

Site : https://companion.os-catalysts.com
